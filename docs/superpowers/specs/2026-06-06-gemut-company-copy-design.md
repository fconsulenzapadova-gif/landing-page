# Gemut Company Copy Rebrand Design

## Goal

Convert public site copy from personal consultant voice to company voice for the brand `Gemüt!`.

## Scope

- Replace visible personal branding such as `Filippo Marcuzzo` with `Gemüt!`.
- Rewrite public-facing copy from first-person singular to company voice: `noi`, `siamo`, `i nostri servizi`.
- State clearly that Gemüt! works in `mediazione immobiliare`.
- Update contact email references to `info@gemutcapital.com`.
- Keep existing layout, routes, imagery, colors, and service structure unchanged.

## Target Pages

- Home landing page.
- Main service pages for purchase, sale, rentals, and personalized services.
- Public request and client access pages where public copy references the consultant or team.
- Shared footer/contact text where the current brand appears.

## Non-Goals

- No visual redesign.
- No route changes.
- No CRM, auth, database, or Supabase behavior changes.
- No changes to uploaded assets.

## Verification

- Search source for old public brand strings after edits.
- Run project lint or build if the current workspace state allows it.
- Open `http://localhost:8080/` and visually check key public pages for Gemüt! company voice and contact email.
