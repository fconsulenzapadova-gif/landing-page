# Project Memory Index

Leggere questo indice all'inizio di ogni task non banale. Aprire solo i documenti pertinenti al lavoro, oltre a `active-context.md` e `progress.md`.

## Memoria canonica

- Prodotto, route, comportamento utente, stato feature: [`../product/PRD.md`](../product/PRD.md)
- Architettura, confini moduli, flussi dati: [`../architecture/overview.md`](../architecture/overview.md)
- Decisioni difficili da invertire: [`../architecture/decisions/`](../architecture/decisions/)
- Setup, comandi, verifiche, workflow esterni: [`../runbooks/development.md`](../runbooks/development.md)
- Convenzioni ricorrenti: [`../patterns/frontend.md`](../patterns/frontend.md)
- Stato lavoro e note handoff: [`active-context.md`](active-context.md)
- Avanzamento sintetico: [`progress.md`](progress.md)

## Regole di aggiornamento

- Aggiornare il documento più specifico; evitare copie della stessa informazione.
- Registrare una decisione solo se costosa o rischiosa da cambiare.
- Tenere note temporanee in `active-context.md`; consolidarle o rimuoverle a task chiuso.
- Aggiungere a `progress.md` solo milestone utili a task futuri, non log dettagliati.
- `PRD.md` in root è solo un puntatore di compatibilità.
